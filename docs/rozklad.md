# Rozkład materiału

**Klasa I · 64 godziny (45 min) · zajęcia w pracowni**

Przedmiot przygotowuje do kwalifikacji **INF.03** (jednostki efektów: INF.03.3 *Projektowanie stron internetowych* i efekt 3 z INF.03.5 *Programowanie aplikacji internetowych*: skrypty po stronie klienta).

Legenda kolumny „Zakres”:

- **P**: treść z podstawy programowej, wymagana na egzaminie
- **P+**: treść z podstawy rozszerzona poza typowy zakres egzaminu
- **★**: treść spoza podstawy (praktyka zawodowa, nowoczesne techniki)

Kody efektów: `3.1` = INF.03.3 efekt 1 (HTML), `3.2` = CSS, `3.4` = grafika, `3.5` = multimedia, `3.6` = strona według projektu, `3.7` = testowanie i optymalizacja, `3.8` = publikacja, `5.3` = JavaScript po stronie klienta, `1` = BHP (INF.03.1).
