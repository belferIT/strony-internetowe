# Lekcja 1. Bezpieczna praca w pracowni i konto GitHub

<p class="lekcja-meta">Dział: Start · 45 min · Efekty: INF.03.1 · <span class="zakres zakres-p">INF.03</span> <span class="zakres zakres-gw">★ GitHub</span></p>

## Cel lekcji

Po tej lekcji potrafisz:

- wymienić zasady bezpiecznej pracy przy komputerze,
- prawidłowo zorganizować stanowisko pracy,
- przygotować folder roboczy na zajęcia,
- założyć konto w serwisie GitHub.

## Wprowadzenie

### Zasady pracy w pracowni

1. Nie jesz i nie pijesz przy komputerze.
2. Nie dotykasz przewodów, gniazdek ani wnętrza komputera. Usterkę zgłaszasz nauczycielowi.
3. Nie zmieniasz ustawień systemu i nie instalujesz programów bez zgody nauczyciela.
4. Swoją pracę zapisujesz w swoim folderze roboczym, nie na pulpicie.
5. Po zajęciach wylogowujesz się i zostawiasz porządek na stanowisku.

### Ergonomia stanowiska

| Element | Jak powinno być |
|---|---|
| Monitor | górna krawędź ekranu na wysokości oczu lub nieco niżej, odległość od oczu 40–75 cm |
| Krzesło | stopy płasko na podłodze, uda równolegle do podłogi, oparcie podpiera dolną część pleców |
| Klawiatura i mysz | przedramiona oparte, nadgarstki proste |
| Oświetlenie | bez odblasków na ekranie, okno z boku, nie za plecami ani przed tobą |
| Przerwy | co ok. 20 minut popatrz przez 20 sekund na coś odległego (zasada 20-20-20) |

!!! warning "Porażenie prądem"
    Gdy ktoś zostanie porażony prądem: **nie dotykaj go**, dopóki nie zostanie odłączone zasilanie. Wyłącz prąd (wyłącznik główny w pracowni) i natychmiast zawiadom nauczyciela. Numer alarmowy: **112**.

### Czym jest GitHub?

GitHub to serwis, w którym programiści przechowują kod i pracują nad nim wspólnie. Za darmo udostępnia też **GitHub Pages**, czyli hosting stron internetowych. W tym roku opublikujesz tam własną stronę.

## Zadanie główne (25 min)

**Część A. Folder roboczy (5 min)**

1. W miejscu wskazanym przez nauczyciela utwórz folder `Nazwisko_Imie` (bez polskich znaków i spacji).
2. W nim utwórz foldery `lekcja-01`, `lekcja-02`, `lekcja-03`.

!!! tip "Dlaczego bez polskich znaków i spacji?"
    W adresach stron internetowych spacje i polskie litery sprawiają kłopoty. Przyzwyczaj się od początku do nazw typu `moja-strona.html`.

**Część B. Konto GitHub (20 min)**

1. Wejdź na [github.com/signup](https://github.com/signup).
2. Załóż konto. Wybierz login **bez swojego imienia i nazwiska**, np. `zielony-kod-24`. Login będzie częścią adresu Twojej strony.
3. Potwierdź adres e-mail.
4. Włącz uwierzytelnianie dwuskładnikowe: *Settings → Password and authentication*.
5. Utwórz repozytorium o nazwie `strony-internetowe`: przycisk **New** (lub **+ → New repository**), zaznacz *Public* i *Add a README file*, kliknij **Create repository**. Tu będziesz publikować prace z tego przedmiotu, pod adresem `https://login.github.io/strony-internetowe/`.
6. Zapisz swój login w pliku `lekcja-01/github.txt`.

!!! warning "Chroń swoje dane"
    Wszystko, co umieścisz na GitHubie, widzi każdy. Nie wpisuj imienia i nazwiska w loginie, opisie profilu, nazwach repozytoriów ani w plikach, które publikujesz.

!!! info "Nie chcesz zakładać konta?"
    Powiedz o tym nauczycielowi: otrzymasz inny sposób publikowania swoich prac.

## Zadanie dla chętnych <span class="zakres zakres-gw">★ poza egzaminem</span>

W repozytorium `strony-internetowe` otwórz plik `README.md` i kliknij ikonę ołówka (*Edit*). Napisz w nim dwa zdania o przedmiocie „Strony internetowe”: czego chcesz się nauczyć i jaką stronę chcesz zrobić. Nie podawaj imienia, nazwiska ani nazwy szkoły. Zapisz zmiany przyciskiem **Commit changes**.
